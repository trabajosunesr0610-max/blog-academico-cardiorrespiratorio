# Blog académico: Alteraciones Cardiorrespiratorias

Sitio web estático y adaptable a móviles, elaborado con HTML, CSS y JavaScript.

## Contenido
- 6 temas cardiovasculares.
- 11 temas respiratorios.
- Sección sobre el papel de la fisioterapia cardiorrespiratoria.
- Glosario básico.
- Buscador de patologías respiratorias y paneles desplegables.

## Cómo visualizarlo
1. Descomprime el archivo ZIP.
2. Abre `index.html` en un navegador.
3. Para publicarlo en GitHub Pages, sube los archivos a la raíz del repositorio y activa Pages desde Settings > Pages, seleccionando la rama `main` y la carpeta `/ (root)`.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable.
- `script.js`: tarjetas, buscador e interacción.

## Nota académica
El contenido es educativo y resumido. Debe ampliarse con bibliografía científica y adaptarse a las guías y protocolos vigentes de la institución.
